## 🧠 Overview

JavaScript data types fall into two main categories:

- **🔹 Primitive Types** — Value-based (immutable), stored directly in memory.
- **🔸 Reference Types** — Object-based (mutable), stored in memory via a reference.

```js
// Primitive type example
let age = 25;

// Reference type example
let user = { name: "Ahmet", age: 25 };
```
